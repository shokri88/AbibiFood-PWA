# محدودیت‌ها و مشکلات شناخته‌شده فرانت

- هشت Route Angular آغازین در برابر ۲۰ صفحه مرجع؛ حساب و باشگاه عملیاتی منتقل نشده‌اند.
- بنر خانه دستی ورق می‌خورد؛ ظاهر مرجع حفظ شده ولی تمام تعاملات legacy عیناً port نشده‌اند.
- پیشنهاد و پرفروش‌ها ترتیب نمونه دارند؛ آماری از فروش وجود ندارد.
- سبد قیمت و موجودی را سمت سرور قفل نمی‌کند؛ دکمه فروش واقعی وجود ندارد.
- تعداد هر افزودنی در Angular فعلاً صفر/یک است. مدل آینده باید تعداد مجاز API را رعایت کند.
- metadata manifest و worker ساخته شده‌اند؛ نصب روی دستگاه، آفلاین و Visual QA هنوز آزموده نشده‌اند.
- mode template پیش‌فرض است؛ بدون تغییر config به API متصل نمی‌شود.
- چند متن هنوز داخل template هستند و مهاجرت به messages JSON کامل نیست.
- cartهای قدیمی قالب HTML مهاجرت داده نمی‌شوند؛ مرجع مستقل فقط برای طراحی است.

این موارد failure تست گزارش نشده‌اند؛ مرز دامنه و کارهای لازم برای ادامه‌اند.
