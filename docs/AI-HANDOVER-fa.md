# نقطه شروع انتقال آبی‌بی — Frontend

## وضعیت این شروع

این مخزن `shokri88/AbibiFood-PWA` است. مخزن همراه: https://github.com/shokri88/AbibiFood-NetCore . مرجع طراحی: AbibiFood-UI در SHA `2af3cb18ef8c3de657fe2284db0209379fc2ee09`.

فرانت فعلی Angular با هشت Route آغازین است؛ قالب ۲۰ صفحه‌ای در `template-reference/` محفوظ است. انتقال کامل صفحات حساب/باشگاه هنوز انجام نشده. حالت پیش‌فرض template با برچسب نمونه است؛ mode=api کاتالوگ واقعی را می‌خواند و در شکست API به داده نمونه fallback نمی‌کند.

با `git log -5 --oneline` و `git status --short` آخرین وضعیت واقعی را بخوانید؛ نام فایل به‌تنهایی نشانه تکمیل قابلیت نیست. این اسناد درباره PC-POS، چاپگر و رزرو کارگاه نیستند. حساب مشتری و درگاه هنوز انتخاب/تعریف نشده‌اند. دسترسی به مخزن همراه برای بررسی سرتاسری لازم است.

نسخه‌ها و نقش فایل‌ها در اسناد همان مخزن ثبت شده‌اند. رازهای اجرا باید توسط مالک خارج از Git تهیه شوند. قطع دسترسی به این حساب ChatGPT نباید مانع ادامه از GitHub شود؛ دسترسی به GitHub و رازهای محیط همچنان مستقل لازم است.
