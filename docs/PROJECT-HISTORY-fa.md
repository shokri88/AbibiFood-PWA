# تاریخچه قابل اتکای پروژه

## منشأ شواهد

این تاریخچه از Git مخزن AbibiFood-UI و گفت‌وگوی واقعاً در دسترس تهیه شده است. متن کامل همه چت‌های حساب یا سابقه خصوصی خارج از Git در دسترس نیست. تاریخ روی پیام‌های قدیمی جایگزین timestamp واقعی Git نشده است.

| مرجع Git قالب | رویداد                                                     |
| ------------- | ---------------------------------------------------------- |
| f258cff       | قالب HTML با دارایی‌ها و جریان سفارش نمایشی                |
| a8439d6       | ۲۰ صفحه مستقل، Bootstrap RTL و صفحات باشگاه                |
| 4203c55       | منوی پایین با سبد، تخفیف و JustValidate                    |
| f38b63e       | شخصی‌سازی مالک؛ صفحات، استایل، تصاویر و لوگوتایپ           |
| 79b724f       | افزودن چهار وب‌فونت Hasti توسط مالک                        |
| c0541be       | CSS مستقل Hasti و اتصال به صفحات                           |
| 2af3cb1       | آخرین مبنای تأییدشده قالب؛ تغییر style.css به style-02.css |

مبنای انتقال قالب: `2af3cb18ef8c3de657fe2284db0209379fc2ee09` در `shokri88/AbibiFood-UI`. مخزن قالب در این شروع تغییر داده نشد.

در گفت‌وگوی بعدی مالک Angular جدید، ظرفیت کل روز و مشترک‌بودن مخزن/موجودی افزودنی و غذای مستقل را تأیید کرد. مدیر و کارمند، پنل Razor، ساختار ساده چهارلایه و نگهداری مستندات فارسی در خود GitHub برای شروع انتخاب شدند. اسناد انتقال کیوسک صرفاً الگوی مستندسازی بودند؛ هیچ قانون کیوسک به آبی‌بی منتقل نشد.

این نسخه شروع دو مخزن جدید است. ادامه‌دهنده باید SHA آخرین main هر دو مخزن را از Git بخواند؛ این سند SHA کامیتِ در حال ایجاد را از پیش حدس نمی‌زند.
