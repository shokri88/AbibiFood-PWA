# وضعیت واقعی فرانت

## پیاده‌شده در این شروع

- Angular 21.2.25، Routeهای splash، branches، home، menu، food/:id، cart، club و account.
- صفحه/قالب/CSS مستقل برای هر Route و اجزای مشترک جدا.
- انتقال دارایی‌های واقعی، Hasti و style-02.css از قالب مالک؛ نسخه مرجع کامل محفوظ.
- حالت template و api؛ API عمومی branch/menu به مدل UI تبدیل می‌شود.
- نمایش قیمت شعبه و تخفیف، انتخاب افزودنی‌های مجاز API، سبد محلی ترکیبی و badge.
- PWA manifest و Angular service worker برای shell/assets؛ API در dataGroups cache نمی‌شود.
- Build production و ۵ تست StoreService موفق؛ فایل تست در مخزن است.

## عمداً عملیاتی نیست

فروش، پرداخت، ورود مشتری، OTP، باشگاه واقعی، رزرو ظرفیت و ثبت فاکتور. cart یک پیش‌نمایش مرورگر است. routeهای club/account فعلاً مرز فاز بعد و لینک مرجع طراحی دارند.

## محدودیت تأیید

مرور بصری، نصب واقعی PWA، Offline روی دستگاه و اتصال به SQL/API واقعی انجام نشده‌اند. نسخه قبلی HTML تست‌های تاریخی جدا دارد؛ آن‌ها به‌عنوان تست Angular گزارش نمی‌شوند.

نسخه‌های مستقیم در package.json دقیق pin شده و package-lock.json ثبت شده است.

## افزودن مستقیم از کارت غذا — ۲۰۲۶-۱۰-۳۱

مبنای تغییر `9752313` است. در خانه، کاروزل تخفیف و منو، کارت مشترک FoodCard دکمه افزودن و کنترل تعداد دارد. لینک «اطلاعات تکمیلی» و تصویر/نام غذا همچنان صفحه مستقل محصول را باز می‌کنند؛ برای افزودن دیگر مجبور به ورود به آن صفحه نیستید.

اولین افزودن از کارت وقتی تعداد آن غذا در سبد صفر است: اگر افزودنی مجاز تعریف شده باشد، dialog بومی مرورگر باز می‌شود؛ در غیر این صورت مستقیم اضافه می‌شود. انتخاب افزودنی اختیاری است و هر افزودنی فعلاً یک واحد همراه هر غذاست. تأیید یک ردیف غذا با addonIds ثبت می‌کند؛ بستن/لغو چیزی اضافه نمی‌کند. افزودن بعدی آخرین ردیف ترکیب همان غذا را افزایش می‌دهد؛ کاهش از همان ردیف شروع می‌شود. عدد کارت مجموع تمام ترکیب‌های آن غذاست. با حذف آخرین واحد، افزودن دوباره انتخاب افزودنی را باز می‌کند. برای ترکیب متفاوت می‌توان از صفحه اطلاعات تکمیلی استفاده کرد.

قیمت تخفیفی در کارت و جمع پاپ‌آپ لحاظ می‌شود. آیتم دارای remaining=0 قابل افزودن نیست و افزودنی ناموجود غیرفعال است؛ این کنترل صرفاً UI است و رزرو/فروش قطعی نیست. سقف قبلی ۲۰ واحد در هر ترکیب حفظ شد؛ تغییر شعبه در زمان نمایش dialog مانع ثبت انتخاب قدیمی در سبد شعبه جدید می‌شود.

در حالت template دو رابطه نمونه افزوده شد: غذاهای ۱ و ۲ می‌توانند غذای ۳ (سیب‌زمینی) را همراه داشته باشند؛ این نمونه از همان مخزن غذاست. mode=api همچنان فقط رابطه‌ها و غذاهای پاسخ API را مصرف می‌کند؛ fallback یا endpoint جدید ساخته نشد. بک‌اند و قالب دست‌نخورده template-reference تغییر نکردند.

اعتبارسنجی: npm run build موفق؛ npm test -- --watch=false شامل ۱۳ تست موفق (۸ سرویس سبد، ۵ کامپوننت کارت)؛ diff check موفق. تست‌ها با JSDOM هستند و showModal/close شبیه‌سازی شده‌اند؛ تست بصری، فوکوس/ESC در مرورگر واقعی و پذیرش روی دستگاه هنوز انجام نشده است.

درخواست سبک‌ترشدن فونت فرانت هنوز کامل نشده: مخزن فقط چهار فایل ثابت Hasti Heavy با وزن CSS ۹۰۰ دارد؛ Regular/Medium موجود نیست. تغییر صوری font-weight وزن واقعی آن فایل را سبک نمی‌کند. فونت هستی و فایل‌های موجود حفظ شدند؛ برای تکمیل نیاز به فایل مجاز وزن سبک‌تر از مالک است.
